# 合并版使用说明

本版面向国际服 **1.58.0 / versionCode 7016**，内含汉化 **v1.5** 数据（743 MiB，2026-11-14，含 271 个剧情包）与帧率悬浮窗。源码构建方式见 [README](../README.md)。

## 安装与启动

1. 安装前确认账号引继方式，并备份必要数据。同包名、不同签名无法覆盖官方版；卸载会清除本地数据。自行构建的签名也可能与旧补丁不同。
2. 安装自行构建的 APK，留足安装包、约 743 MB 解包数据及游戏自身资源所需空间。
3. 首次打开等待汉化数据安装完成（真机实测约 15 秒），程序会自动进入游戏。后续启动按版本标记跳过重复解包。
4. 按系统提示授予悬浮窗权限，重启游戏后可使用独立浮球；未授权时使用游戏内视图兜底。
5. 共存版（`…_andr0id` 包名，应用名 `TLW CN FPS Mod!`）是独立 App，可与官方客户端并存；首次进入需要重新登录（引继）并由游戏下载资源，本地数据不与官方版互通。

## 帧率与汉化修复

轻点浮球打开面板，输入目标帧率并应用；还原默认写回 Unity 的 -1。浮球支持拖动、隐藏与恢复。实际帧率受刷新率、vsync、温控及性能影响。

面板底部有两个应急入口：

| 按钮 | 用途 |
|---|---|
| **缓存修复（汉化变英文时点这里）** | 删安装标记并重启，重新解包汉化资源及对应 `__info`。只修数据，不负责把上游未翻译的内容变中文 |
| **还原官方缓存（黑屏/进不去时点这里）** | 删掉本安装器写过的汉化主表/资源包，重启后**跳过解包直接进游戏**，由游戏重新下载官方数据。用于黑屏、登录无反应等装坏场景；想恢复汉化再点「缓存修复」 |

安装器兜底：数据包与游戏版本不一致时会拒绝解包并提示（不会写坏缓存）；解包失败界面提供「跳过汉化，直接启动游戏」，先保证能玩，之后点「缓存修复」可重装。

## 更新与故障

| 情况 | 处理 |
|---|---|
| 安装提示签名冲突 | 核对已安装客户端的包名与签名，先确认引继和备份，再决定是否卸载 |
| 首启安装失败 | 检查空间与 `assets/lwlocal.zip` 是否完整，按 README 校验数据哈希；实在装不上点「跳过汉化，直接启动游戏」 |
| 进游戏黑屏 / 停在黑屏只有点击特效 | 悬浮窗「还原官方缓存」；若悬浮窗打不开，长按浮球或重启 App 再试 |
| 更换汉化数据却没有重装 | 构建时同步更新 `-CnVersion`，或使用「缓存修复」 |
| 帧率不符合目标值 | 检查屏幕刷新率、温控及游戏版本的 Unity 偏移兼容性 |
| Google 登录失败 | 重签名可能影响签名校验，使用游戏支持的其他账号引继方式 |

新版本游戏需重新核对 APK、ABI、Unity 偏移与汉化数据，不能直接沿用旧版本兼容结论；出包时用 `-GameVersion` 标出新版本，安装器会自动校验。历史设备证据存放在本目录及 `screenshots*/`。
