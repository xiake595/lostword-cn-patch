# 合并版使用说明

本版面向国际服 1.57.0 / versionCode 6728，内含汉化 v1.3 数据与帧率悬浮窗。源码构建方式见 [README](../README.md)。

## 安装与启动

1. 安装前确认账号引继方式，并备份必要数据。同包名、不同签名无法覆盖官方版；卸载会清除本地数据。自行构建的签名也可能与旧补丁不同。
2. 安装自行构建的 APK，留足安装包、445 MB 解包数据及游戏自身资源所需空间。
3. 首次打开等待汉化数据安装完成，程序会自动进入游戏。后续启动按版本标记跳过重复解包。
4. 按系统提示授予悬浮窗权限，重启游戏后可使用独立浮球；未授权时使用游戏内视图兜底。

## 帧率与汉化修复

轻点浮球打开面板，输入目标帧率并应用；还原默认写回 Unity 的 -1。浮球支持拖动、隐藏与恢复。实际帧率受刷新率、vsync、温控及性能影响。

汉化回退英文时，点击“缓存修复”。程序会删除汉化安装标记并重启，重新解包汉化资源及对应 __info；它不负责把尚未翻译的内容变成中文。仍有任务说明、派遣界面等英文，详见根 README 的范围说明。

## 更新与故障

| 情况 | 处理 |
|---|---|
| 安装提示签名冲突 | 核对已安装客户端的包名与签名，先确认引继和备份，再决定是否卸载 |
| 首启安装失败 | 检查空间与 assets/lwlocal.zip 是否完整，按 README 校验数据哈希 |
| 更换汉化数据却没有重装 | 构建时同步更新 -CnVersion，或使用缓存修复 |
| 帧率不符合目标值 | 检查屏幕刷新率、温控及游戏版本的 Unity 偏移兼容性 |
| Google 登录失败 | 重签名可能影响签名校验，使用游戏支持的其他账号引继方式 |

新版本游戏需重新核对 APK、ABI、Unity 偏移与汉化数据，不能直接沿用旧版本兼容结论。历史设备证据存放在本目录及 screenshots/，本次仓库整理没有重新进行真机验证。
