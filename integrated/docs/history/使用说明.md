# 东方归言录（国际服）整合包 使用说明

> 一个安装包 = **帧率解锁悬浮窗** + **简体汉化（v1.3）**
> 对应游戏版本：**1.57.0（versionCode 6728）**　包名/应用名保持官方原样。

---

## 一、安装前必读

1. **先拿到引继码**（游戏内：Menu → 引继），并确认账号已绑定。
   本包签名与官方不同，**不能覆盖安装官方客户端**，必须先卸载官方版。
   `pm uninstall` 会把 `/data/data/<包名>` 一起删掉——没引继码就找不回号。
2. 需要约 **1.1 GB 空闲空间**：APK 本身 630 MB + 首次启动解包汉化数据 445 MB
   （游戏自身下载的资源另算）。空间不够会安装/解包失败。
3. 如果你之前装过本项目的帧率解锁包（`TLW-global-1.57.0-fps.apk`，同签名同包名），
   **不用卸载**，直接装这个新包覆盖升级即可，存档和已下载资源都保留。

## 二、安装步骤

1. 卸载官方客户端（如果还在）：
   - 手机：设置 → 应用 → 东方归言录(国际服) → 卸载；或
   - 电脑 adb：`adb uninstall jp.goodsmile.touhoulostwordglobal_android`
2. 安装 `TLW-global-1.57.0-cn-fps.apk`（拖进模拟器/手机点击安装，或 `adb install`）。
3. 打开游戏（图标名仍是 `Touhou LostWord`）。
   - **首次启动**会先出现深色进度界面：「东方归言录 汉化安装 / 正在安装汉化资源（约 445 MB）」。
     正常几秒~一分钟（模拟器实测 3.8 秒），**不要退出、不要杀进程**。
   - 进度到 100% 后自动进入游戏；以后每次启动直接进游戏。
4. 首次进游戏如果提示「显示在其他应用上层」权限（悬浮球用），点允许；
   不给也能用，只是悬浮球会退化为游戏内视图（拖动会略卡）。

## 三、帧率悬浮球怎么用

- 屏幕角落一个圆形小球，显示当前写入的帧率（`60` / `OFF` 等）。
- **拖动**：按住拖到任意位置，松手记住坐标。
- **轻点**：弹出面板，输入 10~480 之间的数字后点「应用」。
- **还原默认帧率**：写回游戏原厂值。
- **隐藏悬浮窗**：收起成半透明小点；点小点回来；长按小点彻底关闭（本次进程内）。
- 帧率要和屏幕刷新率成整数分之一才真正跑满（例：165 Hz 屏可设 165/83/55/41/33/28；
  60 Hz 屏设 60/30/20/15）。面板会实时显示「实际 ≈ xx」，输入非整数分频会被量化。

### 缓存修复按钮（汉化变英文时用）

面板里新增了「**缓存修复（汉化变英文时点这里）**」按钮。用途：

- 游戏在**首次登录下载资源、版本更新、或手动清缓存**后，可能把它自己缓存里的汉化资源包
  清掉/重新下载，表现是**角色名、UI 标签回退成英文**（技能名、道具名等主数据表内容通常还是中文）。
- 这时点一下这个按钮：App 会自动重启，重启后进度界面会显示「检测到汉化资源需要修复，
  正在重新安装…」，把内置的 445 MB 汉化数据重新解包一遍，完成后自动进游戏。
- 全程约 10 秒（真机实测 1.5 秒解包 + 重启），不需要 root/adb，**不会动你的账号和存档**。
- 如果点了之后游戏没有自动弹回来（部分系统会拦截后台自启动），手动点桌面图标打开游戏即可，
  它同样会自动重新解包。

## 四、汉化说明

- 汉化内容来自开源项目 `xiake595/lostword-cn-patch` v1.3：
  剧情主角台词 9,851 条、技能/符卡/能力名 5,117 条、主数据表 84 张、资源包 345 个、
  字体按国服还原。
- 汉化数据在首次启动时写入游戏自己的缓存目录，游戏不会重复下载这部分资源。
- **已知仍未汉化**：任务说明（如 `Log in on 5 days`）、部分 UI 标签（`Switch Effect` 等）、
  伙伴卡片上的 ATK/SUPP 职业标记（图片）、服务器下发的活动横幅。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 安装报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 设备上还有官方版或旧签名包，先彻底卸载再装 |
| 安装报空间不足 | 清出 ≥1.1 GB 空间；模拟器要扩 userdata 分区 |
| 首次启动卡在进度条 | 确认空间足够（尤其 `/sdcard` 与 `/data` 是同一分区时）；杀掉重开会从断点覆盖重跑，是安全的 |
| 进度界面一闪就进游戏 | 说明本机已经装过汉化数据，属正常快路径 |
| 进游戏仍显示英文/角色名英文 | 点悬浮球 → 「缓存修复（汉化变英文时点这里）」，App 会自动重启并重装汉化数据；若没自动弹回来，手动点桌面图标打开游戏即可。仍不行确认游戏版本是 1.57.0 |
| 游戏更新后汉化失效/异常 | 换版本必须重新出包（数据只对应 1.57.0） |
| 想恢复原版 | 卸载本包，装回官方客户端，用引继码登录 |

## 六、想删掉汉化数据但保留游戏

需要 root 或 adb shell 权限：

```bash
# 删除主数据表
adb shell "rm -f /data/data/jp.goodsmile.touhoulostwordglobal_android/files/cache/*"
# 删除资源包（游戏之后会按需重新下载）
adb shell "rm -rf /sdcard/Android/data/jp.goodsmile.touhoulostwordglobal_android/files/UnityCache/Shared/*"
# 删除安装标记（否则不会重装）
adb shell "rm -f /data/data/jp.goodsmile.touhoulostwordglobal_android/files/tlw_cn/installed.txt"
```
