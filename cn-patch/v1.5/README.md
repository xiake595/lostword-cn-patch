# 东方归言录 国际服 简体中文补丁 v1.5

> 适用于 `jp.goodsmile.touhoulostwordglobal_android` **1.58.0**
> 不修改 APK、不改变签名，随时可还原。

---

## 这个补丁做了什么

| 部分 | 内容 |
|---|---|
| **界面文本** | 菜单、按钮、提示、弹窗等 UI 文本 |
| **界面图片** | 主界面按钮、属性图标（日/月/火/水/木/金/土/星/无）、御伽文库等 |
| **字体** | 换成能显示全部汉字的字体（国服同款方正雅宋 GBK，22,002 字形） |
| **绘卷** | 绘卷名、5 段解说、被动特性（5325 格） |
| **角色能力** | 能力名与描述 |
| **技能 / 特性** | 技能名、技能效果描述、特性 |
| **剧情** | 主线、活动、角色剧情、对话、选项（271 个剧情包） |
| **其余主表** | 共 79 张表 |

**没有做的**：**角色名**（`UnitMaster`）。原因见下面「已知问题」。

## 三个命令

```bash
# 安装
python tlw_install.py install

# 检查装好了没
python tlw_install.py verify

# 还原成英文
python tlw_install.py restore
```

**默认目标是 `emulator-5556`**（LDPlayer 实例 1）。换设备加 `--serial`：

```bash
python tlw_install.py install --serial 127.0.0.1:5555
```

只想看会做什么、不实际写入：

```bash
python tlw_install.py install --dry-run
```

## 前置条件

1. **游戏已安装并至少启动过一次**（要它先把资源缓存生成出来）
2. **设备已 root**（写游戏私有目录需要）。模拟器一般自带；真机需自行解决
3. **adb 可用**。脚本按顺序找：环境变量 `ADB` → `C:\leidian\LDPlayer14\adb.exe` → PATH 里的 adb

---

## 安装后怎么确认生效

1. 重启游戏
2. 进**伙伴**界面 → 应正常显示角色列表（不是黑屏）
3. 进**绘卷**界面 → 绘卷名和说明是中文
4. 进**主线 / 活动剧情** → 对话是中文，不黑屏

再跑一遍 `verify`，资源包 / 主表 / 剧情三类都显示「不一致 0」就算装好了。

**游戏更新后补丁失效？** 补丁绑版本号，更新后需重新适配，不要强行套用。

**剧情黑屏？** 该篇章资源包与游戏版本不匹配，`restore` 还原后重新确认。

## 常见问题

**某处还是英文？**
那个界面还没被游戏加载过，对应的缓存条目不存在。进该界面一次，再重跑 `install` 即可补上（脚本会自动跳过设备上没有的条目）。

**装完闪退 / 界面黑屏？**
先 `restore` 还原，确认游戏正常，然后把 `install-test.log` 里的错误发出来。

**游戏更新后补丁失效？**
补丁是绑版本号的。更新后需要重新制作对应版本的补丁，不要强行套用。

**还原后还是中文？**
重启游戏。如果仍不对，说明游戏已经重新下载了资源，`restore` 里的备份可能已被覆盖。

## 已知问题

### 角色名仍是英文

`UnitMaster` 这张表有一个未解决的技术问题：**只要文件长度发生变化，游戏进「伙伴」界面就会黑屏。**

已排除：加密方式（已改无填充 CBC）、改动量（只改 1 格也黑屏）、msgpack 结构（不改内容能逐字节还原）。

目前最强的线索是文件中间偏移 446656 处有一块 16 字节未知数据，可能是校验值，含义未确认。因此这张表**暂不包含在补丁里**，角色名保持英文。

### 任务卡片背景

任务界面某些卡片背景是国际服原生设计，国服没有，无法通过贴图替换消除。

## 原理（给技术用户）

**两类补丁写在不同位置：**

| 类型 | 设备路径 | 说明 |
|---|---|---|
| 资源包 / 剧情 | `Android/data/<pkg>/files/UnityCache/Shared/<c>/<e>/__data` | 旁边还有一个 `__info`，必须写成 `-1\n<epoch>\n1\n__data`，epoch 等于新 `__data` 的 mtime，否则 Unity 判定缓存失效会重新下载 |
| 主表 | `/data/user/0/<pkg>/files/cache/<hash>` | AES-128-CBC 加密，写完要 `chown <游戏UID>:<游戏UID>` + `chmod 600`（UID 从设备实时读取，各机器安装顺序不同，不能写死） |

**剧情与资源包的区别**：资源包只覆盖设备上已存在的缓存条目；剧情包在条目不存在时会主动创建目录和文件对，所以没下载过的篇章也能预置。

**还原**：安装时把原文件备份到设备 `/data/local/tmp/tlw-v15-backup/`，`restore` 从这里恢复。
